# 문자열 덧셈 계산기

## 기능 목록


### 1. 덧셈 안내문 출력
  - [x] "덧셈할 문자열을 입력해 주세요." 출력하기

        
### 2. 문자열 입력받기
  - [x] 구분자와 양수로 구성된 문자열 입력받기
  - [x] 기본 구분자(쉼표, 콜론) 등록
  - [x] 커스텀 구분자(//과 \n 사이의 문자) 둥록
  - [x] 잘못된 값을 입력 받은 경우 IllegalArgumentException을 발생

        
### 3. 문자열을 구분자를 기준으로 분리
  - [x] 구분자를 기준으로 문자열 분리
        

### 4. 문자열 숫자로 변환 및 덧셈 연산
  - [x] 문자열 숫자 변환
  - [x] 양수 범위 벗어나는 숫자(예외 발생, 예시:음수)
  - [x] 숫자가 아닌 문자(예외 발생)
  - [x] 분리된 숫자 합 계산

        
### 5. 결과 출력하기
  - [x] "결과 : "라는 문구와 함께 결과를 출력한다.
